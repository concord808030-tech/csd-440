# CSD 440 – Server-Side Scripting (PHP)

Assignments for CSD 440. Everything runs on a local Apache + PHP + MySQL stack (XAMPP).

## Setup

1. Install XAMPP and start **Apache** (and **MySQL** for Modules 8 and 9).
2. Copy or clone this repo into `C:\xampp\htdocs\`.
3. Open an assignment in the browser, e.g. `http://localhost/csd-440/Module_10/miguel_json_form.html`.

Modules 8 and 9 connect as `student1` / `pass` to the `baseball_01` database. Module 8 keeps those settings in `Module_8/MiguelDbConfig.php`.
